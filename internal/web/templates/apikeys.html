New API key

Keys give applications read-only access to the archive: search, page metadata and text, captured files, HTML exports, WARC records and weekly WACZ packages. They cannot change anything and do not open the web interface.

Using a key

Send it in the Authorization header:

curl -H "Authorization: Bearer hfr_…" /api/pages?after=0

  • GET /api/pages?after= new captures since a cursor
  • GET /api/search?q= full-text search with filters
  • GET /api/facets sources, storages and kinds for filters
  • GET /api/pages/{id} metadata and extracted text
  • GET /api/pages/{id}/content the captured file

Specification for client generators: openapi.yaml. Guide: docs/api.md.
